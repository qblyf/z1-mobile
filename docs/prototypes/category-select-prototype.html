实现说明

数据获取

// 1. 获取顶级分类
GET /category/top  → 26条顶级分类

// 2. 获取子级分类
GET /category/list?type=1  → 9298条数据
// pid = 0 表示顶级
// pid = 父级ID 表示子级

// 3. 获取 SPU
GET /spu/list?cateId=X  → 该分类下的商品

// 4. Tab 参数
// type=1: 商品
// type=7: 服务

分类数据结构

Category {
  id: number,       // 分类ID
  name: string,     // 分类名称
  spell: string,    // 拼音码
  pid: number,     // 父级ID（0=顶级）
  order: number,    // 排序
  type: number,     // 类型（1=商品，7=服务）
  state: number,    // 状态
  chain: number[],  // 分类链
}
