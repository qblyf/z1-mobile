实现说明

⚠️ 重要设计说明

服务分类层级不确定（无限层级），采用面包屑导航：
- 顶部显示面包屑：全部 › 分类1 › 分类2 › ...
- 点击分类进入下一级
- 如果还有子分类 → 显示子分类列表
- 如果没有子分类 → 显示服务列表
- 点击面包屑可返回上级
- 搜索时清空面包屑，直接显示结果

数据获取

// 1. 获取服务分类
GET /category/list?type=7  → 服务分类列表

// 2. 获取服务列表
GET /serve/list?cateID={id}  → 该分类下的服务
GET /serve/list?keyWord={keyword}  → 搜索结果

// 3. 获取服务数量
GET /serve/count?cateID={id}  → 服务总数

服务数据结构

Service {
  id: number,
  name: string,        // 服务名称
  shortName: string,   // 简称
  cent: number,        // 价格（分）
  cate: number,        // 分类ID
  isGoods: 1 | 2,    // 是否绑定序列号
  mainImages: string[], // 主图列表
  description: string,  // 服务描述
}

与商品选择的区别

对比项 商品选择 服务选择
分类体系 商城分类（3级固定） 进销存分类（无限层级）
导航方式 左侧固定分类面板 面包屑逐级展开
列表接口 /spu/list /serve/list
展示形式 网格卡片（图片为主） 列表卡片（文字为主）
