### 2.3 核心交互逻辑

#### 今日概览

- 显示当前日期和天气（预留）
- 今日销售金额和订单数（从零售单接口获取）
- 待处理审批数量
- 待办任务数量

#### 待办审批区块

- 显示最近 3 条待处理审批
- 每项显示：审批类型、摘要、申请人、时间
- 状态标签：调拨审批（橙）/ 退货审批（蓝）/ 价格特批（紫）
- 点击列表项 → 跳转审批详情
- 点击"查看全部" → 跳转审批中心

#### 今日待办区块

- 显示今日待办任务（最多 3 条）
- 每项显示：任务标题、完成状态、计划时间、优先级
- 点击列表项 → 跳转任务详情
- 点击"查看全部" → 跳转任务列表

#### 快捷操作

两个快捷入口：

| 入口 | 图标 | 路由 | 说明 |
|------|------|------|------|
| 零售开单 | 🛒 | `/home/retail/entry` | 快速开单 |
| 序列号查询 | 🔍 | `/inventory/serial-search` | 快速查询 |

#### 消息通知入口

- 顶部右侧铃铛图标
- 显示未读消息数量（红色角标）
- 点击 → 跳转消息通知列表

### 2.4 字段说明

#### 今日概览（TodaySummary）

| 字段 | 类型 | 说明 |
|------|------|------|
| date | string | 当前日期 |
| weather | string | 天气（预留）|
| temperature | string | 温度（预留）|
| todaySales | int | 今日销售金额（分）|
| todayOrders | int | 今日订单数 |
| pendingApprovals | int | 待处理审批数 |
| pendingTasks | int | 待办任务数 |

#### 待办审批项（ApprovalSummary）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 审批单 ID |
| type | enum | 类型：`transfer`/`return`/`price_special` |
| summary | string | 审批摘要 |
| applicantName | string | 申请人姓名 |
| createdAt | int | 申请时间戳（秒）|

#### 今日待办项（TaskSummary）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 任务 ID |
| title | string | 任务标题 |
| completed | bool | 是否已完成 |
| planTime | string | 计划时间（格式：HH:mm）|
| priority | enum | 优先级：`high`/`medium`/`low` |

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 今日概览加载失败 | 显示错误提示，可重试 |
| 待办审批为空 | 区块显示"暂无待处理审批" |
| 今日待办为空 | 区块显示"暂无待办任务" |
| 消息数量加载失败 | 铃铛不显示数量 |

## 三、模块数据流

```
工作台首页
    │
    ├── 获取今日概览数据
    │   ├── 今日销售 → /order/shop-sale-count
    │   ├── 待处理审批 → /approval/count
    │   └── 待办任务 → /task/list
    │
    ├── 获取待办审批列表 → /approval/list
    │
    ├── 获取今日待办列表 → /task/list
    │
    ├── 获取消息未读数 → /notification/unread-count（预留）
    │
    └── 快捷操作入口
        ├── 零售开单 → /home/retail/entry
        └── 序列号查询 → /inventory/serial-search

API 调用序列：
1. GET  /order/shop-sale-count      → 今日销售统计
2. GET  /approval/count            → 审批数量统计
3. GET  /approval/list             → 待办审批列表
4. GET  /task/list                 → 待办任务列表
5. GET  /notification/unread-count → 消息未读数（预留）
```

## 四、接口清单

> **注意**：金额字段单位为分（cent），非元。数量字段为整数。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 工作台首页 | `/order/shop-sale-count` | GET | 今日销售统计 |
| 工作台首页 | `/approval/count` | GET | 审批数量统计 |
| 工作台首页 | `/approval/list` | GET | 待办审批列表（筛选待处理）|
| 工作台首页 | `/task/list` | GET | 待办任务列表（筛选今日/待完成）|
| 工作台首页 | `/notification/unread-count` | GET | 消息未读数（预留）|
