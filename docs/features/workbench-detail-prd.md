### 2.3 核心交互逻辑

#### 快捷操作

- 四个快捷入口：零售开单、扫码、序列号查询、查会员
- 点击直接跳转对应功能页面
- 无需二次确认

#### 待办事项

- 待审批数量：显示红点+数字，点击跳转审批中心
- 今日任务数量：显示数字，点击跳转任务列表
- 点击卡片整体也可跳转

#### 消息通知

- 显示最新一条系统通知
- 红点表示有未读消息
- 点击查看更多消息列表

#### 下拉刷新

- 下拉刷新重新加载工作台数据

### 2.4 字段说明

#### 工作台数据（WorkbenchSummary）

| 字段 | 类型 | 说明 |
|------|------|------|
| pendingApprovalCount | int | 待审批数量 |
| todayTaskCount | int | 今日任务数量 |
| notifications | List<Notification> | 通知列表 |
| shortcuts | List<ShortcutItem> | 快捷入口配置 |

#### 快捷入口（ShortcutItem）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 入口 ID |
| name | string | 入口名称 |
| icon | string | 图标名称 |
| route | string | 跳转路由 |
| badge | string | 角标（可选）|

#### 通知（Notification）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 通知 ID |
| title | string | 通知标题 |
| content | string | 通知内容（可选）|
| time | datetime | 通知时间 |
| isRead | bool | 是否已读 |
| type | string | 通知类型 |

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 网络错误 | 显示错误页，点击重试 |
| 待办数量为 0 | 显示"暂无待办" |
| 无通知 | 显示"暂无通知" |
| 加载中 | 显示骨架屏 |

## 三、快捷操作详解

### 3.1 零售开单

```
点击 → /order/retail/entry
    → 选择销售类型
    → 商品选购
    → 收款
    → 完成
```

### 3.2 扫码

```
点击 → 调起相机
    → 扫描商品条码
    → 查询商品信息
    → 或进入序列号查询
```

### 3.3 序列号查询

```
点击 → /inventory/serial-search
    → 输入/扫描序列号
    → 查看商品详情
```

### 3.4 查会员

```
点击 → /member/home
    → 搜索会员
    → 查看会员详情
```

## 四、模块数据流

```
工作台加载
    ├── 获取待审批数量
    ├── 获取今日任务数量
    ├── 获取通知列表
    └── 配置快捷入口

API 调用序列：
1. GET /approval/count           → 待审批数量
2. GET /task/today-count         → 今日任务数量
3. GET /notification/list        → 通知列表
```

## 五、接口清单

> **注意**：金额字段单位为分（cent），非元。数量字段为整数。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 工作台 | `/approval/count` | GET | 待审批数量 |
| 工作台 | `/task/today-count` | GET | 今日任务数量 |
| 工作台 | `/notification/list` | GET | 通知列表 |
