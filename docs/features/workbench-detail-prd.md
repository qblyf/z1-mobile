### 2.3 核心交互逻辑

#### 今日概览

- 显示当前日期和天气（预留）
- 今日销售金额和订单数（从零售单接口获取）
- 待处理审批数量
- 待办任务数量

#### 待办审批区块

- 显示最近 3 条待处理审批
- 每项显示：审批类型、摘要、申请人、时间
- 状态标签：调拨审批（橙）/ 退货审批（蓝）/ 价格特批（紫）
- 点击列表项 → 跳转审批详情
- 点击"查看全部" → 跳转审批中心

#### 今日待办区块

- 显示今日待办任务（最多 3 条）
- 每项显示：任务标题、完成状态、计划时间、优先级
- 点击列表项 → 跳转任务详情
- 点击"查看全部" → 跳转任务列表

#### 快捷操作

两个快捷入口：

| 入口 | 图标 | 路由 | 说明 |
|------|------|------|------|
| 零售开单 | 🛒 | `/home/retail/entry` | 快速开单 |
| 序列号查询 | 🔍 | `/inventory/serial-search` | 快速查询 |

#### 消息通知入口

- 顶部右侧铃铛图标
- 显示未读消息数量（红色角标）
- 点击 → 跳转消息通知列表

## 三、模块数据流

```
工作台首页
    │
    ├── 获取今日概览数据
    │   ├── 今日销售 → /order/shop-sale-count
    │   ├── 待处理审批 → /approval/count
    │   └── 待办任务 → /task/list
    │
    ├── 获取待办审批列表 → /approval/list
    │
    ├── 获取今日待办列表 → /task/list
    │
    ├── 获取消息未读数 → /notification/unread-count（预留）
    │
    └── 快捷操作入口
        ├── 零售开单 → /home/retail/entry
        └── 序列号查询 → /inventory/serial-search

API 调用序列：
1. GET  /order/shop-sale-count      → 今日销售统计
2. GET  /approval/count            → 审批数量统计
3. GET  /approval/list             → 待办审批列表
4. GET  /task/list                 → 待办任务列表
5. GET  /notification/unread-count → 消息未读数（预留）
```

## 四、接口清单

> **注意**：金额字段单位为分（cent），非元。数量字段为整数。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 工作台首页 | `/order/shop-sale-count` | GET | 今日销售统计 |
| 工作台首页 | `/approval/count` | GET | 审批数量统计 |
| 工作台首页 | `/approval/list` | GET | 待办审批列表（筛选待处理）|
| 工作台首页 | `/task/list` | GET | 待办任务列表（筛选今日/待完成）|
| 工作台首页 | `/notification/unread-count` | GET | 消息未读数（预留）|

## 五、状态流转

工作台是聚合展示页，**自身无状态机**。展示的子模块状态：

| 子模块 | 状态字段 | 说明 |
|--------|---------|------|
| 审批待办 | `ApprovalStatus.pending` | 见 approval-types.dart:37-53 |
| 任务待办 | TaskStatus（待办/进行中/已完成） | 见 task-types.dart |
| 红点数量 | `/approval/count` | 工作台加载时调用一次，无轮询 |
