### 2.3 核心交互逻辑

#### 快捷操作

- 4 个快捷操作入口：零售开单、扫码、查序列号、查会员
- 点击直接跳转到对应功能页面
- 零售开单 → `/order/retail/entry`
- 其他快捷操作为占位符

#### 待办审批

- 显示最近 3 条待审批项
- 每项显示：图标、标题、摘要、时间/标签
- 点击可进入审批详情（预留）
- "查看全部审批" → `/approval/center`
- 显示红点数字角标（待处理数量）

#### 今日任务

- 显示今日及近期任务
- 每项显示：图标、标题、截止时间、优先级标签
- 优先级标签：紧急（红）/ 普通 / 低
- 点击可进入任务详情（预留）

#### 消息通知

- 显示最近 3 条系统通知
- 每项显示：标题、内容、时间
- 点击进入通知详情（预留）
- 显示红点数字角标（未读数量）

### 2.4 字段说明

#### 快捷操作项（QuickAction）

| 字段 | 类型 | 说明 |
|------|------|------|
| icon | IconData | 图标 |
| label | string | 名称 |
| color | Color | 主题色 |
| route | string | 跳转路径 |

#### 审批项（ApprovalItem）

| 字段 | 类型 | 说明 |
|------|------|------|
| icon | string | emoji 图标 |
| title | string | 审批类型 |
| subtitle | string | 审批摘要 |
| tag | string | 标签（可选，如"紧急"）|
| tagColor | Color | 标签颜色 |
| time | string | 时间描述 |

#### 任务项（TaskItem）

| 字段 | 类型 | 说明 |
|------|------|------|
| icon | string | emoji 图标 |
| title | string | 任务标题 |
| subtitle | string | 任务描述 |
| tag | string | 标签（可选，如"紧急"）|
| tagColor | Color | 标签颜色 |
| time | string | 时间/截止日期描述 |

#### 通知项（NotificationItem）

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 通知标题 |
| content | string | 通知内容摘要 |
| time | string | 发布时间 |

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 无待办审批 | 显示"暂无待审批项" |
| 无今日任务 | 显示"暂无待完成任务" |
| 无消息通知 | 显示"暂无新通知" |
| 网络错误 | 显示错误提示，可重试 |

## 三、模块数据流

```
工作台
├── 快捷操作 → 各功能页面
├── 待办审批 → /approval/center
├── 今日任务 → /task/home
└── 消息通知 → /notification

API 调用序列：
1. GET  /approval/list            → 待审批列表（预留）
2. GET  /task/today               → 今日任务（预留）
3. GET  /notification/unread-count → 未读通知数（预留）
```
