### 2.3 核心交互逻辑

#### 销售类型选择

- 默认选中"零售"
- 点击切换选中状态，高亮边框
- 不同销售类型影响后续商品显示价格（零售价/批发价/工程价）

#### 会员绑定

**方式一：企微扫码**

1. 点击企微扫码入口
2. 调起相机扫描二维码
3. 识别会员身份，自动填充会员信息
4. 显示搜索结果卡片

**方式二：手机号查找**

1. 输入手机号（11位数字键盘）
2. 点击"查找"按钮
3. 调用 `/members/search-by-phones` 接口
4. 有结果 → 显示会员卡片（姓名、等级、积分）
5. 无结果 → 显示红色提示"该手机号未注册为会员"

#### 绑定/解绑

- 找到会员后显示"已绑定"标签
- 可点击"解除绑定"按钮移除绑定
- 解绑后恢复到散客状态

#### 开始开单

- 点击底部"开始开单"按钮
- 携带参数：`saleType` + `customerId?`（可选）
- 跳转到 `/order/retail/product`

### 2.4 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| saleType | enum | 销售类型：`retail`/`wholesale`/`project` |
| customerId | string | 会员 ID（可选，null 表示散客）|
| customerName | string | 会员姓名（展示用）|

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 手机号不足 11 位 | 查找按钮禁用 |
| 手机号格式错误 | 输入框红色边框 + 提示 |
| 会员不存在 | 显示"该手机号未注册为会员" |
| 扫码失败/无法识别 | Toast 提示"无法识别，请重试" |
| 网络错误 | 显示"网络异常，请检查网络" |

### 2.6 跳转关系

| 来源 | 触发 | 目标 |
|------|------|------|
| 首页菜单 | 点击"零售开单" | /order/retail/entry |
| /order/retail/entry | 点击"开始开单" | /order/retail/product |
| /order/retail/entry | 点击顶部返回 | /home |

### 3.3 核心交互逻辑

#### 商品分类

- 左侧分类列表，支持滚动
- 点击分类 → 筛选商品列表
- 默认显示"全部"

#### 商品网格

- 2 列网格布局
- 每个商品卡片显示：
  - 商品图片/图标
  - 商品名称（超长截断）
  - 零售价（原价）
  - 会员价（更低价）
  - 库存状态（有货/无货/库存不足）
- 点击商品卡片 → 查看商品详情弹窗

#### 添加购物车

- 点击商品卡片的"+"按钮
- 商品加入购物车，数量 +1
- 购物车浮动栏同步更新（数量 + 金额）

#### 扫码添加

- 点击顶部"扫码"按钮
- 调起相机扫描商品条码
- 找到商品 → 自动加入购物车 + Toast 提示
- 未找到 → 显示"商品不存在"

#### 搜索

- 输入商品名称或条码
- 点击搜索/回车 → 调用 `/product/search`
- 显示搜索结果列表

#### 购物车浮动栏

- 显示：商品数量 + 总金额
- 点击"去结算" → 跳转到订单确认页
- 点击购物车图标 → 展开购物车抽屉（可修改数量/删除）

#### 购物车抽屉

- 展开显示所有已选商品
- 每项可修改数量（-/+ 按钮）
- 可删除商品（向左滑动或点击删除图标）
- 点击"清空"可清空购物车

| 字段 | 类型 | 说明 |

| skuId | string | SKU ID（可选）|
| name | string | 商品名称 |
| price | int | 单价（分，根据 saleType 取对应价格）|
| quantity | int | 数量 |

### 3.5 异常/边界情况

### 4.3 核心交互逻辑

#### 会员信息展示

- 散客不可使用

#### 订单备注

- 可选字段，最多 200 字符
- 不影响主流程

- 计算优惠后的应收金额

### 5.3 核心交互逻辑

#### 支付方式选择

- 点击支付方式卡片选中
- 四种方式：现金、微信支付、支付宝、银行卡
- 默认选中现金

#### 现金收款

- 显示实收金额输入框
- 预设默认金额为应付金额
- 点击"恰好"按钮 → 实收金额 = 应付金额
- 实时计算找零金额（找零 = 实收 - 应付）
- 找零为负数时显示红色提示"金额不足"

#### 二维码收款（微信/支付宝）

- 显示收款二维码
- 二维码有效期 5 分钟
- 超时后自动刷新
- 需轮询支付结果（调用 `/order/:orderNumber/payment-status`）

#### 确认收款

- 验证：实收金额 ≥ 应付金额（现金）
- 调起后端接口创建订单：
  - 接口：`POST /order/shop-sale/add`
  - 携带：customerId、saleType、items、couponId、experienceAmount、payment
- 成功 → 跳转订单详情页（/order/:orderNumber）
- 失败 → 显示错误提示，可重试

### 5.4 字段说明

#### 支付信息（Payment）

| 字段 | 类型 | 说明 |
|------|------|------|
| method | enum | 支付方式：`cash`/`wechat`/`alipay`/`card` |
| receivedAmount | decimal | 实收金额（现金时）|
| changeAmount | decimal | 找零金额 = receivedAmount - finalAmount |
| transactionId | string | 第三方交易号（扫码支付时）|

#### 订单创建请求（AddShopSaleParams）

```json
{
  "customerId": "string",      // 会员ID（可选）
  "saleType": "retail",         // 销售类型
  "items": [
    {
      "productId": "string",
      "skuId": "string",        // 可选
      "quantity": 1,
      "price": 2800.00,
      "discount": 0
    }
  ],
  "payment": {
    "method": "cash|wechat|alipay|card|combined",
    "amount": 21378,
    "subPayments": []
  },
  "couponId": "string",         // 优惠券ID（可选）
  "couponAmount": 120,          // 优惠券抵扣金额
  "experienceAmount": 200,      // 积分抵扣金额（可选）
  "remarks": "string"           // 订单备注（可选）
}
```

### 5.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 现金实收 < 应付 | 按钮禁用，提示"金额不足" |
| 二维码支付超时 | 自动刷新二维码，提示"二维码已刷新" |
| 订单创建失败 | 显示错误原因，可重试 |
| 网络断连 | 缓存订单数据，恢复后自动提交 |
| 支付中用户取消 | 保持当前页面，不自动跳转 |

### 5.6 跳转关系

| 来源 | 触发 | 目标 |
|------|------|------|
| /order/retail/confirm | 点击"去收款" | /order/retail/payment |

## 八、模块数据流

```
用户选择销售类型 → 选择/绑定会员 → 添加商品到购物车 → 确认订单（优惠+积分） → 收款 → 创建订单 → 订单详情

API 调用序列：
1. POST /members/search-by-phones      → 查找会员
2. GET  /product/search                → 搜索商品
3. GET  /product/list                  → 获取商品列表
4. GET  /members/coupon-list           → 获取可用优惠券
5. GET  /members/experience/:memberId  → 获取会员积分（需传会员ID）
6. POST /order/shop-sale/add           → 创建零售单
7. GET  /order/:orderNumber            → 获取订单详情
8. GET  /order/:orderNumber/print      → 打印小票
```

## 九、接口清单

> **注意**：金额字段（如 price、amount 等）单位为**分（cent）**，非元。
> 例如 price: 280000 表示 ¥2800.00。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 开单入口 | `/members/list-phones` | POST | 手机号查找会员 |
| 商品选购 | `/product/list` | GET | 商品列表（按分类/搜索）|
| 商品选购 | `/product-price/list` | GET | 获取商品价格（零售价/批发价/工程价，根据 saleType 筛选）|
| 订单确认 | `/coupons/self` | GET | 获取当前会员可用优惠券 |
| 订单确认 | `/members/experience` | POST | 获取/计算会员积分抵扣（需传会员ID） |
| 收款 | `/order/shop-sale/add` | POST | 创建零售单 |
| 订单详情 | `GET /order-product/list?orderID=xxx` | GET | 订单商品明细列表 |
| 订单详情 | `/order/:orderNumber/print` | GET | 打印小票 |
