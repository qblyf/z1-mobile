### 5.11 全局状态与跨模块跳转

#### 全局 Toast / Modal 通知
- 操作成功 → 全局 Toast（自动消失）
- 操作失败 → 全局 Modal（带重试按钮）
- 网络异常 → 全局 Banner（重试/忽略）

#### 订单状态跨模块联动
```
订单状态变更 → 触发通知
├── 零售单完成 → 会员积分变动
├── 退货单审核 → 库存变动
├── 预订单确认 → 生成正式订单
└── 调拨单完成 → 源/目标门店库存变动
```

#### 会员行为跨模块联动
```
会员消费 → 关联订单
     ↓
触发积分变动 → 更新会员积分
     ↓
满足升级条件 → 自动升级会员等级
     ↓
推送升级通知 → App通知
```

#### 审批通过跨模块联动
```
审批通过 → 触发对应操作
├── 退货审批通过 → 执行退款 + 库存回退
├── 调拨审批通过 → 解锁调拨操作
├── 价格特批审批 → 订单应用特殊价格
└── 新品采购审批 → 解锁采购入库
```

---

### 5.12 异常链路（边界情况）

```
商品搜索无结果
└── 空状态提示 → 引导扫码或手动输入条码

会员手机号未注册
└── 空状态 → 是否新建会员？→ /member/add

扫码商品不在库
└── 提示：商品不存在 → 可手动输入条码

收款二维码失效
└── 提示超时 → 重新生成二维码

网络断线（离线操作）
└── 数据本地缓存 → 网络恢复后自动同步
    └── 冲突检测 → 提示用户确认

库存不足
└── 提示：库存不足，是否继续提交缺货订单？

调拨目标门店已关闭
└── 下拉选项禁用 + 提示

审批已被其他审批人处理
└── 刷新页面 → 显示最新状态
```

|------|----------|----------|

| 订单数据 | 缓存最近 7 天 | 实时同步 |
| 会员数据 | 缓存最近访问 | 实时同步 |

| 类型 | 方案 |
|------|------|
| 小票打印 | 蓝牙打印机（ESC/POS 协议） |
| 标签打印 | 蓝牙标签打印机 |

| 风险 | 影响 | 应对 |
|------|------|------|
