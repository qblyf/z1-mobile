| 触发路径 | 触发方式 | 流程 |
|---------|---------|------|

| 退货退款完成页 | "打印退款小票"按钮 | 待确认是否需要 |

打印机设置页路径（如需独立页面）：`/profile/printer-setting`（待确认）。

## 三、技术实现

### 3.1 蓝牙打印流程

```
┌─────────────────────────────────────────┐
│ 1. 检查蓝牙权限                          │
│    ↓                                    │
│ 2. 扫描蓝牙设备                         │
│    ↓                                    │
│ 3. 连接打印机（存储配对）               │
│    ↓                                    │
│ 4. 构造 ESC/POS 指令                    │
│    ↓                                    │
│ 5. 发送打印数据                         │
│    ↓                                    │
│ 6. 等待打印完成                         │
└─────────────────────────────────────────┘
```

### 3.2 ESC/POS 指令说明

| 功能 | 指令 | 说明 |
|------|------|------|
| 初始化 | `0x1B 0x40` | 重置打印机 |
| 居中 | `0x1B 0x61 0x01` | 居中对齐 |
| 左对齐 | `0x1B 0x61 0x00` | 左对齐 |
| 粗体开 | `0x1B 0x45 0x01` | 开启粗体 |
| 粗体关 | `0x1B 0x45 0x00` | 关闭粗体 |
| 字号大 | `0x1D 0x21 0x11` | 增大字号 |
| 字号小 | `0x1D 0x21 0x00` | 标准字号 |
| 切纸 | `0x1D 0x56 0x00` | 执行切纸 |

## 六、核心交互逻辑

> ⚠️ Flutter 项目当前未实现打印小票模块（`z1_mobile/lib/features/` 下无 print 目录），z1-pwa 因属 Web 应用也无原生蓝牙打印代码。本节为产品规划。

### 6.1 首次打印

```
用户点击"打印小票"
   ↓
是否已配对打印机？
   ├─是→ 直接连接（如已断开）→ 发送 ESC/POS 指令 → 打印
   └─否→ 进入"打印机设置"
          ↓
       扫描蓝牙设备列表 → 用户选择 → 配对 → 保存到本地
          ↓
       返回打印 → 发送指令 → 打印
```

### 6.2 自动打印模式

- 设置开启"收款后自动打印"
- 收款流程的 `/order/sale-shop-add` 返回成功后，自动触发打印
- 失败不阻塞页面流转（异步打印 + 失败提示 Toast）

### 6.3 重复打印

- 订单详情页"打印小票"按钮可多次点击
- 每次都触发完整流程（不缓存上次打印结果）
- 多份打印通过"打印份数"配置（默认 1）

### 6.4 蓝牙连接管理

| 阶段 | 行为 |
|------|------|
| App 启动 | 不主动连接（节电） |
| 进入需打印页面 | 检查上次配对打印机，后台尝试连接 |
| 点击打印 | 如未连接立即连接 |
| 连接断开 | 静默重连 1 次，失败则提示用户 |
| App 退出 | 断开连接 |

### 6.5 ESC/POS 指令构造

参考第 3.2 节指令表，按以下顺序拼装：

1. 初始化（`0x1B 0x40`）
2. 居中 + 粗体 + 大字号 → 打印门店名称
3. 切回左对齐 + 普通字号 → 打印订单信息
4. 分隔线
5. 循环打印商品明细
6. 分隔线
7. 打印金额汇总（合计/优惠/实付）
8. 打印支付方式 + 会员信息
9. 切纸（`0x1D 0x56 0x00`）

## 七、状态流转

打印小票模块**无业务状态机**。涉及的状态：

| 状态 | 含义 | 来源 |
|------|------|------|
| 蓝牙状态 | 未开启 / 已开启 / 连接中 / 已连接 | 系统蓝牙 API |
| 打印机配对状态 | 未配对 / 已配对 | 本地存储 |
| 打印任务状态 | 排队 / 打印中 / 完成 / 失败 | 内存任务队列 |
| 自动打印开关 | 开 / 关 | 本地设置 |

### 7.1 打印任务生命周期

```
[排队] → [发送指令] → [打印中] ──成功──→ [完成]
                          │
                          └──失败──→ [失败]（可重试）
```
