## 三、技术实现

### 3.1 蓝牙打印流程

```
┌─────────────────────────────────────────┐
│ 1. 检查蓝牙权限                          │
│    ↓                                    │
│ 2. 扫描蓝牙设备                         │
│    ↓                                    │
│ 3. 连接打印机（存储配对）               │
│    ↓                                    │
│ 4. 构造 ESC/POS 指令                    │
│    ↓                                    │
│ 5. 发送打印数据                         │
│    ↓                                    │
│ 6. 等待打印完成                         │
└─────────────────────────────────────────┘
```

### 3.2 ESC/POS 指令说明

| 功能 | 指令 | 说明 |
|------|------|------|
| 初始化 | `0x1B 0x40` | 重置打印机 |
| 居中 | `0x1B 0x61 0x01` | 居中对齐 |
| 左对齐 | `0x1B 0x61 0x00` | 左对齐 |
| 粗体开 | `0x1B 0x45 0x01` | 开启粗体 |
| 粗体关 | `0x1B 0x45 0x00` | 关闭粗体 |
| 字号大 | `0x1D 0x21 0x11` | 增大字号 |
| 字号小 | `0x1D 0x21 0x00` | 标准字号 |
| 切纸 | `0x1D 0x56 0x00` | 执行切纸 |

### 3.3 打印服务

```dart
class PrintService {
  /// 检查蓝牙权限
  Future<bool> checkBluetoothPermission();

  /// 扫描蓝牙设备
  Future<List<BluetoothDevice>> scanDevices();

  /// 连接打印机
  Future<bool> connect(BluetoothDevice device);

  /// 断开连接
  Future<void> disconnect();

  /// 打印小票
  Future<bool> printReceipt(OrderModel order, List<OrderProduct> products);
}
```

## 五、异常处理

| 场景 | 处理 |
|------|------|
| 蓝牙未开启 | 提示开启蓝牙 |
| 未连接打印机 | 提示连接打印机 |
| 打印失败 | Toast "打印失败，请重试" |
| 纸张用完 | 提示检查纸张 |
| 打印机忙碌 | 等待后重试 |
