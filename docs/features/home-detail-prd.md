### 2.3 核心交互逻辑

#### 2.3.1 顶部状态栏

- 显示当前门店名称（只读）
- 右侧通知按钮带红点数字（未读消息数量）
- 点击通知 → 跳转 `/notification`

#### 2.3.2 欢迎语区块

- 显示：用户头像（姓名首字母）、角色+姓名、日期
- 欢迎语文案可配置（默认"今日加油，业绩翻倍！"）

#### 2.3.3 快捷操作

- 三个快捷按钮：
  - **快速扫码**：调起相机扫码（商品条码/序列号）
  - **查序列号**：跳转 `/inventory/serial-search`
  - **查会员**：跳转 `/member/home`（自动弹出搜索框）
- 点击后直接触发对应功能

#### 2.3.4 今日数据卡片

- 两个数据卡片：
  - **今日销售额**：金额 + 同比昨日涨跌（↑12% / ↓5%）
  - **今日订单数**：订单总数 + 已完成数
- 数据调用 `/dashboard/today-stat` 接口
- 下拉刷新更新数据

#### 2.3.5 功能菜单（6 个）

| 菜单 | 路由 | 优先级 | 说明 |
|------|------|--------|------|
| 零售开单 | `/order/retail/entry` | P0 | 直接进入开单 |
| 订单列表 | `/order/list` | P0 | 查看订单 |
| 库存管理 | `/inventory/home` | P0 | 盘库/调拨/采购入口 |
| 会员中心 | `/member/home` | P1 | Tab 切换到会员 |
| 行事历 | `/task/calendar` | P2 | Tab 切换到任务 |
| 审批中心 | `/approval/center` | P2 | Tab 切换到工作台，含红点（待处理数量）|

**审批中心红点逻辑**：
- 显示待处理审批数量
- 无待处理时隐藏红点

#### 2.3.6 最近订单

- 显示最近 3 条订单
- 每条显示：订单号、时间、金额、状态
- 点击"查看全部 >" → 跳转 `/order/list`
- 点击单个订单 → 跳转 `/order/:orderNumber`

#### 2.3.7 待处理事项

- 显示最多 3 条待处理事项
- 类型：待审批（红色）、待完成任务（黄色）、调拨待确认（蓝色）
- 点击跳转对应处理页面

#### 2.3.8 底部 TabBar

- 5 个 Tab：首页 / 会员 / 工作台 / 任务 / 我的
- 当前 Tab 高亮（蓝色图标+文字）
- 点击切换 Tab，刷新对应页面

### 2.4 字段说明

#### 今日数据（TodayStat）

| 字段 | 类型 | 说明 |
|------|------|------|
| todaySales | int | 今日销售额（分）|
| salesChangePercent | decimal | 销售额同比涨跌百分比 |
| todayOrderCount | int | 今日订单总数 |
| completedOrderCount | int | 已完成订单数 |

#### 最近订单项（OrderSummary）

| 字段 | 类型 | 说明 |
|------|------|------|
| orderNumber | string | 订单号 |
| orderType | enum | 订单类型：`retail`/`wholesale`/`project` |
| createdAt | datetime | 下单时间（显示"X分钟前"）|
| finalAmount | int | 实收金额（分）|
| status | enum | 状态：`pending`/`completed`/`refunded` |
| customerName | string | 客户姓名（散客显示"零售"）|

#### 待处理事项（PendingItem）

| 字段 | 类型 | 说明 |
|------|------|------|
| type | enum | 类型：`approval`/`task`/`transfer` |
| title | string | 事项标题 |
| subtitle | string | 事项描述 |
| priority | enum | 优先级：`urgent`/`normal`/`low` |
| targetUrl | string | 点击跳转目标路由 |
| badge | string | 红点数字（可选）|

#### 门店信息（Store）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 门店 ID |
| name | string | 门店名称 |

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 网络断开 | 显示缓存数据，顶部显示网络异常提示条 |
| 无今日销售数据 | 显示"-"，不显示涨跌 |
| 无最近订单 | 显示空状态"暂无订单" |
| 无待处理事项 | 隐藏"待处理事项"区块 |
| 门店信息加载中 | 显示"加载中..."骨架屏 |
| 审批红点数字 > 99 | 显示"99+" |
| 用户未登录 | 跳转登录页（路由守卫处理）|

## 三、首页数据流

```
用户打开 App → Token 检查 → 有 Token → 加载首页数据
                                     ↓
                        并行请求：
                        1. /user/self         → 用户信息 + 门店
                        2. /dashboard/today-stat  → 今日数据
                        3. /order/shop-sale-list?page=1&pageSize=3  → 最近订单
                        4. /pending/items     → 待处理事项（待确认接口）

Tab 切换：
点击会员 Tab → /member/home（不在首页区块内）
```

## 四、接口清单

> **注意**：金额字段单位为分（cent），非元。

| 页面区块 | 接口 | 方法 | 说明 |
|----------|------|------|------|
| 门店卡片 | `/members/self` | GET | 获取当前用户信息（含门店）|
| 今日数据 | `/order/shop-sale-list` + `/order/shop-sale-count` | GET | 用日期筛选聚合今日统计（无专门 dashboard 接口）|
| 最近订单 | `/order/shop-sale-list` | GET | 订单列表（pageSize=3）|
| 待处理审批 | `/approval/count` | GET | 待审批数量（筛选 pending 状态）|
| 待处理任务 | `/task/count` | GET | 待办任务数量（筛选 pending 状态）|

**说明**：
- 今日数据接口：调用 `/order/shop-sale-list?minCreatedDate=今日0点&pageSize=1` 取列表 + `/order/shop-sale-count?minCreatedDate=今日0点` 取总数
- 待处理事项：分别调用 `/approval/count` 和 `/task/count` 后在端聚合展示
