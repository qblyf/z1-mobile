### 2.3 核心交互逻辑

#### 扫码查询

1. 点击"扫描序列号/二维码"按钮
2. 调起相机（mobile_scanner）
3. 识别到序列号/二维码后自动查询
4. 调用 `/goods/serial-search` 接口
5. 有结果 → 显示商品信息和进出库记录
6. 无结果 → Toast "未找到该序列号"

#### 手动输入查询

1. 在输入框中输入序列号
2. 点击"查询"按钮
3. 调用 `/goods/serial-search` 接口
4. 逻辑同扫码查询

#### 查询结果展示

- 商品信息卡片：名称、SKU、条码
- 库存信息卡片：当前仓库、库存数量、商品状态
- 进出库记录：时间、操作类型、来源/去向、操作员
- 点击"再次查询" → 清空结果，恢复扫码入口状态

### 2.4 字段说明

#### 序列号查询请求

| 字段 | 类型 | 说明 |
|------|------|------|
| serialNo | string | 序列号/二维码内容 |

#### 序列号查询响应（SerialSearchResult）

| 字段 | 类型 | 说明 |
|------|------|------|
| goods | object | 商品信息 |
| goods.id | int | 商品 ID |
| goods.name | string | 商品名称 |
| goods.sku | string | SKU |
| goods.barcode | string | 条码 |
| goods.weight | string | 重量（如"30g"）|
| goods.category | string | 商品分类 |
| currentWarehouse | object | 当前仓库信息 |
| currentWarehouse.id | int | 仓库 ID |
| currentWarehouse.name | string | 仓库名称 |
| currentQuantity | int | 当前库存数量 |
| status | enum | 状态：`in_stock`/`sold`/`transferred` |
| traceList | array | 进出库记录列表 |

#### 进出库记录（TraceRecord）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 记录 ID |
| time | int | 操作时间戳（秒）|
| type | enum | 类型：`inbound`/`outbound`/`transfer_in`/`transfer_out` |
| sourceNo | string | 来源单号（采购单/调拨单/销售单）|
| targetNo | string | 去向单号 |
| warehouseId | int | 仓库 ID |
| warehouseName | string | 仓库名称 |
| operatorId | int | 操作员 ID |
| operatorName | string | 操作员姓名 |
| remark | string | 备注（可选）|

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 序列号不存在 | Toast "未找到该序列号，请检查是否输入正确" |
| 序列号已被销售 | 显示商品已售出信息，无库存记录 |
| 序列号在调拨中 | 显示调拨状态和当前位置 |
| 网络错误 | 显示错误提示，可重试 |
| 扫码超时 | 提示"扫码超时，请重试" |

## 三、扫码流程详解

### 3.1 扫码触发

1. 点击"扫描序列号/二维码"按钮
2. 调起相机（mobile_scanner）
3. 识别到条码后自动查询

### 3.2 条码查询

- 调用 `GET /goods/serial-search?serialNo=:code`
- 有结果 → 显示商品信息卡片 + 进出库记录
- 无结果 → Toast "未找到该序列号"

### 3.3 扫码场景

| 场景 | 条码类型 | 处理 |
|------|----------|------|
| 序列号查询 | 自定义序列号 | 查询商品及进出库记录 |
| 序列号查询 | 二维码 | 解析内容后查询 |
| 序列号不存在 | — | Toast 提示 |

## 四、模块数据流

```
扫码/输入序列号 → 查询接口 → 展示结果 → 再次查询/返回

API 调用序列：
1. GET  /goods/serial-search      → 序列号查询
2. GET  /product/barcode/:code   → 条码查商品（备用）
```
