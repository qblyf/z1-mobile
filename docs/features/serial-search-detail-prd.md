### 2.4 核心交互逻辑

#### 搜索输入

- 支持手动输入序列号或条码
- 支持回车键提交搜索
- 输入框带有清除按钮（有内容时显示）
- 点击"搜索"按钮触发查询

#### 仓库筛选

- 显示当前用户有权限的仓库列表
- 点击仓库标签进行筛选
- 筛选影响搜索结果的库存位置显示
- 支持取消筛选（显示全部仓库）

#### 扫码查询

- 可调用相机扫描条码或序列号
- 扫描后自动填充到搜索框并触发查询

#### 搜索结果展示

- 商品基本信息（名称、规格、条码、序列号、分类）
- 当前库存位置（仓库名称、柜位）
- 进出库历史（最近5条）
- 入库/出库标签（绿色/红色）
- 关联订单号

### 2.5 字段说明

#### 序列号查询结果（SerialSearchResult）

| 字段 | 类型 | 说明 |
|------|------|------|
| productId | int | 商品 ID |
| productName | string | 商品名称 |
| spec | string | 规格（可选）|
| barcode | string | 条码（可选）|
| serialNumber | string | 序列号（可选）|
| categoryName | string | 商品分类（可选）|
| location | WarehouseLocation | 当前库存位置 |
| stockFlows | List<StockFlow> | 进出库历史 |

#### 仓库位置（WarehouseLocation）

| 字段 | 类型 | 说明 |
|------|------|------|
| warehouseId | int | 仓库 ID |
| warehouseName | string | 仓库名称 |
| cabinetPosition | string | 柜位（可选）|

#### 进出库记录（StockFlow）

| 字段 | 类型 | 说明 |
|------|------|------|
| flowType | enum | 类型：`in`（入库）/ `out`（出库）|
| flowTypeLabel | string | 类型标签："入库"/"出库" |
| quantity | int | 数量 |
| flowTime | int | 时间戳（秒）|
| orderNumber | string | 关联订单号（可选）|

### 2.6 异常/边界情况

| 场景 | 处理 |
|------|------|
| 输入为空 | 搜索按钮禁用 |
| 商品不存在 | 显示错误页"未找到商品信息" |
| 网络错误 | 显示错误提示，点击重试 |
| 无进出库记录 | 不显示历史区块 |
| 仓库列表为空 | 不显示仓库筛选栏 |

## 三、模块数据流

```
序列号查询 → 输入/扫码 → 查询 → 显示结果（商品+位置+历史）

API 调用序列：
1. GET  /warehouse/list-base        → 获取仓库列表（筛选用）
2. GET  /goods/serial-search        → 序列号/条码查询
```

## 四、接口清单

> **注意**：金额字段单位为分（cent），非元。数量字段为整数。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 序列号查询 | `/goods/serial-search` | GET | 序列号/条码查询商品信息 |
| 序列号查询 | `/warehouse/list-base` | GET | 仓库列表（筛选用）|
