### 2.4 核心交互逻辑

#### 搜索输入

- 输入框支持手动输入序列号或条码
- 点击"搜索"按钮或按回车触发查询
- 调用 `POST /goods/serial-search` 接口

#### 仓库筛选

- 显示当前用户有权限的仓库列表
- 点击仓库标签筛选
- 不选则默认查所有仓库

#### 扫码查询

- 点击输入框右方的扫码按钮
- 调起相机扫描商品条码或序列号二维码
- 识别到条码后自动查询

#### 结果展示

- 商品基本信息：名称、规格、条码、序列号、分类
- 当前库存位置：仓库名称、柜位信息
- 进出库历史：最近 5 条记录，显示类型、数量、时间、单号

#### 进出库记录

- `in`（入）：绿色标记，显示"+数量"
- `out`（出）：红色标记，显示"-数量"

### 2.5 字段说明

#### 序列号查询结果（SerialSearchResultModel）

| 字段 | 类型 | 说明 |
|------|------|------|
| productId | int | 商品 ID |
| productName | string | 商品名称 |
| spec | string | 规格（可选）|
| barcode | string | 条码（可选）|
| serialNumber | string | 序列号（可选）|
| categoryName | string | 商品分类（可选）|
| location | WarehouseLocationModel | 当前库存位置（可选）|
| stockFlows | List<StockFlowModel> | 进出库历史 |

#### 仓库位置（WarehouseLocationModel）

| 字段 | 类型 | 说明 |
|------|------|------|
| warehouseId | int | 仓库 ID |
| warehouseName | string | 仓库名称（可选）|
| cabinetPosition | string | 柜位（可选）|

#### 进出库记录（StockFlowModel）

| 字段 | 类型 | 说明 |
|------|------|------|
| flowType | string | 类型：`in`（入）/ `out`（出）|
| flowTypeLabel | string | 类型标签：入库/出库 |
| quantity | int | 数量 |
| flowTime | int | 时间戳（秒）|
| orderNumber | string | 关联单号（可选）|

### 2.6 异常/边界情况

| 场景 | 处理 |
|------|------|
| 查询为空 | 显示空状态"请输入序列号或条码" |
| 商品不存在 | Toast "未找到该商品" |
| 网络错误 | 显示错误页，点击重试 |
| 加载中 | 显示 CupertinoActivityIndicator |
| 无仓库权限 | 该仓库标签不显示 |

## 三、扫码流程详解

### 3.1 扫码触发

1. 点击输入框右侧扫码图标
2. 调起相机（mobile_scanner）
3. 识别到条码后自动查询

### 3.2 条码查询

- 调用 `POST /goods/serial-search`
- 有结果 → 显示商品信息、库存位置、进出库记录
- 无结果 → Toast "未找到该商品"

### 3.3 扫码场景

| 场景 | 条码类型 | 处理 |
|------|----------|------|
| 序列号查询 | 自定义/二维码 | 查询商品及进出库记录 |
| 快速查询 | EAN-13/UPC-A | 等同于条码查询 |
