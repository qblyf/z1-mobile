## 二、页面 1：我的主页

### 2.1 路由

```
路径：/profile
名称：我的（My Profile）
Tab：TabBar 第 5 项（我的）
```

### 2.2 页面结构

#### 2.2.1 用户信息卡片

- 用户头像（姓名首字母或真实头像）
- 用户姓名 + 角色
- 所属门店名称

#### 2.2.2 功能菜单

**门店信息**：
- 显示当前门店信息（只读）
- 点击跳转门店详情页 `/store/detail`

**账号设置**：
- 跳转账号设置页 `/account/setting`

**数据看板**：
- 跳转数据看板页 `/dashboard/sales`

**消息通知**：
- 显示未读消息数量红点
- 点击跳转消息列表 `/notification`

**使用帮助**：
- 跳转帮助中心 `/help`

**操作日志**：
- 跳转操作日志页 `/log/operation`

#### 2.2.3 底部

**版本信息**：
- 显示当前 App 版本号

**退出登录**：
- 红色按钮，点击弹出确认对话框
- 确认后清除 Token，跳转登录页 `/login`

### 2.3 字段说明

#### ProfileUser（用户信息）

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | number | 用户 ID |
| name | string | 用户姓名 |
| role | string | 角色（如"收银员"）|
| phone | string | 手机号 |
| avatar | string | 头像 URL（可选）|

#### StoreInfo（门店信息）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 门店 ID |
| name | string | 门店名称 |
| address | string | 门店地址（可选）|

### 2.4 接口清单

| 页面区块 | 接口 | 方法 | 说明 |
|----------|------|------|------|
| 用户信息 | `/members/self` | GET | 获取当前用户信息（含门店）✅ |
| 消息数量 | `/notification/unread-count` | GET | ❌ **接口缺失**（404，后端未实现）|

**说明**：
- 用户信息使用首页同接口 `/members/self`
- 消息通知功能暂不可用，需后端实现 `/notification/*` 接口

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| Token 过期 | 跳转登录页 `/login` |
| 用户信息加载失败 | 显示占位头像，提示刷新 |
| 退出登录 | 弹出确认对话框，确认后清除本地数据 |
