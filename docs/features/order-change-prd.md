## 一、页面路径总览

```
换货
├── /order/list              → 订单列表（筛选 types=3）
│         ↓
│   /order/:orderNumber     → 订单详情（显示换货商品）
│         ↓
│   /order/change/add       → 新建换货（调用门店换货/网销换货/批发换货）
```

**⚠️ 重要说明**：
- 换货是销售订单的一种类型，通过 `type = 3`（SalesType.change）标记
- 换货订单通过 `/order/shop-sale-list?types=3` 筛选
> ⚠️ 注意：后端 Order 类型使用 `type` 字段表示销售类型，不是 `salesType`
- 后端只有创建换货接口 `/order-change/add/shop-sale`（门店换货）、`/order-change/add/net-sale`（网销换货）、`/order-change/add/out-sale`（批发换货）
- **⚠️ 暂未发现换货列表/详情接口**，需向产品确认是否需要开发

## 三、新建换货

### 3.1 路由

```
路径：/order/change/add
名称：新建换货
参数：sourceOrderNumber（原订单号）
```

### 3.3 核心交互逻辑

1. 选择原订单 → 自动加载原订单商品作为换出商品
2. 添加换入商品 → 选择新商品
3. 系统自动计算差价
4. 提交换货 → 调用换货接口

## 四、类型定义

### 4.1 销售类型

> 参考 `sales-types.ts` SalesType

```dart
enum SalesType {
  sale(1),     // 卖
  refunds(2),  // 退
  change(3);   // 换

  final int value;
  const SalesType(this.value);
}
```

### 4.2 换货订单字段

换货订单复用销售订单字段，通过 `type = 3` 标记：

> ⚠️ 注意：`Order` 类型中使用 `type` 字段表示 SalesType，而非 `salesType`

```dart
// Order 类型（订单主表）
class Order {
  final int orderID;                // 订单 ID
  final String orderNumber;         // 订单号
  final int type;                   // SalesType: 1=卖, 2=退, 3=换
  final int orderAmount;            // 订单总价（分）
  final int discountAmount;         // 折扣后总价（分）
  final int? revenueAmount;         // 收入金额（分）
  final int? paymodeAmount;         // 商家实收（分）
  // ... 其他字段
}

// ShopSale 类型（零售单扩展）
class ShopSale {
  final int shopSaleID;
  final int shopSaleOrderID;       // 关联 OrderID
  final int? incCoins;             // 增加积分
  final int? decCoins;             // 消耗积分
}
```
