### 4.3 核心交互逻辑

#### 基本信息

- 任务标题：必填，限制 50 字符
- 任务内容：选填，限制 500 字符

#### 时间设置

- 开始时间：必填，点击选择日期时间
- 结束时间：选填，需晚于开始时间
- 时间选择器：日期 + 小时分钟

#### 优先级

- 三个选项：低 / 中 / 高
- 默认：中
- 单选

#### 提醒设置

- 下拉选择：无 / 5分钟前 / 15分钟前 / 30分钟前 / 1小时前
- 默认：无
- 设置后，系统在指定时间发送通知

#### 关联会员

- 点击搜索会员
- 调用 `/members/list-phones` 搜索
- 选择后显示会员姓名和手机号

#### 保存任务

- 点击"保存任务"按钮
- 调用 `POST /task/add` 接口
- 成功 → 跳转任务详情或返回列表
- 失败 → 显示错误提示

## 六、字段说明

### 6.1 任务（Task）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 任务 ID |
| title | string | 任务标题 |
| content | string | 任务内容 |
| startTime | int | 开始时间戳（秒）|
| endTime | int | 结束时间戳（秒，可选）|
| priority | enum | 优先级：`low`/`medium`/`high` |
| remindAt | int | 提醒时间戳（秒，可选）|
| status | enum | 状态：`pending`/`completed`/`expired` |
| memberId | int | 关联会员 ID（可选）|
| memberName | string | 关联会员姓名（可选）|
| memberPhone | string | 关联会员手机号（可选）|
| createdAt | int | 创建时间戳（秒）|
| updatedAt | int | 更新时间戳（秒）|

### 6.2 新建任务请求（AddTaskRequest）

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 任务标题（必填）|
| content | string | 任务内容（可选）|
| startTime | int | 开始时间戳（秒，必填）|
| endTime | int | 结束时间戳（秒，可选）|
| priority | string | 优先级（默认 medium）|
| remindAt | int | 提醒时间戳（秒，可选）|
| memberId | int | 关联会员 ID（可选）|

### 6.3 行事历事件（CalendarEvent）

| 字段 | 类型 | 说明 |
|------|------|------|
| date | string | 日期（格式：YYYY-MM-DD）|
| tasks | array | 当日任务列表 |
| hasEvent | bool | 是否有任务 |

## 七、异常/边界情况

| 场景 | 处理 |
|------|------|
| 任务列表为空 | 显示空状态"暂无任务" + "新建任务"引导 |
| 日历无任务 | 日期下方无圆点标记 |
| 网络错误 | 显示错误提示，可重试 |
| 状态加载中 | 显示骨架屏 |
| 任务已过期 | 状态标签显示红色"已过期" |
| 未选择开始时间 | 保存按钮禁用 |

| 来源 | 触发 | 目标 |

| TabBar | 点击"任务" | /task/home |

| /task/home | 点击任务项 | /task/:id |
| /task/list | 点击任务项 | /task/:id |
| /task/list | 点击"+" | /task/add |

| /task/add | 点击顶部返回 | /task/home |

## 九、模块数据流

```
任务/行事历首页
    │
    ├── 日历视图 → 获取日历数据 → /task/calendar
    │       ↓
    │   选择日期 → 显示当日任务
    │
    ├── 列表视图 → /task/list
    │       ↓
    │   状态筛选 → 刷新列表
    │
    ├── 新建任务 → /task/add
    │       ↓
    │   提交成功 → 任务详情
    │
    └── 任务详情 → /task/:id
            ↓
            标记完成/编辑/删除

API 调用序列：
1. ~~GET  /task/calendar~~              → ❌ **接口缺失**（404，后端未实现）
2. GET  /task/list                  → 获取任务列表 ✅
3. POST /task/add                   → 创建任务 ✅
4. GET  /task/:id                  → 获取任务详情 ✅
5. ~~POST /task/:id/edit~~           → ❌ **接口路径待确认**（可能为 PUT /task/:id）
6. POST /task/:id/complete          → 完成任务 ✅
7. DELETE /task/:id/delete         → 删除任务 ✅
```
