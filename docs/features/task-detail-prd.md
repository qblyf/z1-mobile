### 2.3 核心交互逻辑

#### 任务分组

- 按时间范围分组：今日任务 / 本周任务 / 已完成
- 每组显示任务数量

#### 任务卡片

- 每项显示：优先级图标、标题、截止时间
- 优先级图标：
  - 高优先级：红色感叹号 ⚠
  - 中优先级：实心圆 ●
  - 低优先级：空心圆 ○
- 已完成任务：绿色勾选 ✓，带删除线

#### 任务状态

- 待完成：正常显示，有右箭头
- 已完成：灰色文字，带删除线，无右箭头

#### 优先级说明

| 优先级 | 图标 | 颜色 | 说明 |
|--------|------|------|------|
| 高 | exclamationmark_circle_fill | 红色 | 紧急任务 |
| 中 | circle_fill | 橙色 | 普通任务 |
| 低 | minus_circle_fill | 绿色 | 低优先级任务 |

### 2.4 字段说明

#### 任务项（Task）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 任务 ID |
| title | string | 任务标题 |
| deadline | string | 截止时间描述 |
| priority | enum | 优先级：`high`/`medium`/`low` |
| isCompleted | bool | 是否已完成 |
| createdAt | datetime | 创建时间 |

#### 优先级枚举（TaskPriority）

| 值 | 标签 | 图标 |
|------|------|------|
| high | 高优先级 | exclamationmark_circle_fill |
| medium | 中优先级 | circle_fill |
| low | 低优先级 | minus_circle_fill |

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 无今日任务 | 显示"暂无今日任务" |
| 无本周任务 | 显示"暂无本周任务" |
| 无已完成任务 | 隐藏"已完成"分组 |
| 网络错误 | 显示错误提示，可重试 |

### 2.6 跳转关系

| 来源 | 触发 | 目标 |
|------|------|------|
| TabBar | 点击"任务" | /task/home |
| /task/home | 点击"+"按钮 | /task/add（预留）|
| /task/home | 点击任务卡片 | /task/:id（预留）|
| /task/home | 点击顶部返回 | /home |

## 三、模块数据流

```
任务首页
├── 今日任务 → 查看/操作
├── 本周任务 → 查看/操作
└── 已完成任务 → 查看

API 调用序列：
1. GET  /task/list             → 获取任务列表（按状态分组）
2. POST /task/add              → 新建任务（预留）
3. PUT  /task/:id/complete     → 标记完成（预留）
```

## 四、接口清单

> **注意**：当前为占位符实现，以下接口为预留。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 任务列表 | `/task/list` | GET | 任务列表（按状态筛选）|
| 新建任务 | `/task/add` | POST | 创建任务 |
| 任务详情 | `/task/:id` | GET | 任务详情 |
| 标记完成 | `/task/:id/complete` | PUT | 标记任务完成 |
| 删除任务 | `/task/:id` | DELETE | 删除任务 |
