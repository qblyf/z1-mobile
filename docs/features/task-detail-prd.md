### 2.3 核心交互逻辑

#### 日历导航

- 显示当前月份
- 点击左右箭头切换月份
- 点击日期可快速查看该日任务

#### 日期选择

- 点击日期 → 显示该日任务列表
- 有任务的日期显示圆点标记
- 今日自动高亮

#### 今日任务列表

- 显示选中日期的所有任务
- 每项显示：复选框、任务标题、时间、优先级
- 已完成任务显示删除线
- 点击任务 → 跳转任务详情

#### 新建任务

- 点击底部"+ 新建任务"按钮
- 跳转 `/task/add`

#### 任务筛选

- Tab：全部 / 待完成 / 已完成
- 筛选当前日期范围内的任务

### 2.4 字段说明

#### 任务项（TaskSummary）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 任务 ID |
| title | string | 任务标题 |
| description | string | 任务描述（可选）|
| startTime | datetime | 开始时间 |
| endTime | datetime | 结束时间（可选）|
| priority | enum | 优先级：`high`/`medium`/`low` |
| status | enum | 状态：`pending`/`completed` |
| isAllDay | bool | 是否全天 |

#### 任务优先级（Priority）

| 值 | 说明 | 颜色 |
|------|------|------|
| high | 高 | 红色 |
| medium | 中 | 橙色 |
| low | 低 | 灰色 |

### 2.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 无任务 | 显示空状态"当日暂无任务" |
| 网络错误 | 显示错误页，点击重试 |
| 加载中 | 显示骨架屏 |
| 任务时间冲突 | 显示警告但允许保存 |

### 2.6 跳转关系

| 来源 | 触发 | 目标 |
|------|------|------|
| /task/home | 点击日期 | 显示该日任务 |
| /task/home | 点击任务 | /task/:id |
| /task/home | 点击"+ 新建任务" | /task/add |
| /task/home | 点击 Tab | 筛选任务列表 |
| /task/home | 点击顶部返回 | /home |


### 3.3 核心交互逻辑

#### 任务标题

- 必填，最少 1 个字符
- 最大长度 100 字符

#### 时间选择

- 点击时间选择器，弹出日期时间选择器
- 开始时间必填
- 结束时间可选（选则验证 > 开始时间）

#### 全天任务

- 勾选后隐藏时间选择，只保留日期

#### 优先级选择

- 三个选项：高 / 中 / 低
- 默认选中"中"

#### 提醒设置

- 下拉选项：不提醒 / 提前 5 分钟 / 提前 15 分钟 / 提前 30 分钟 / 提前 1 小时
- 默认"不提醒"

#### 保存任务

- 调用 `POST /task/add` 创建任务
- 必填校验：标题、开始时间
- 成功 → 跳转任务详情或返回列表

### 3.4 字段说明

#### 新建任务请求（AddTaskRequest）

| 字段 | 类型 | 说明 |
|------|------|------|
| title | string | 任务标题 |
| description | string | 任务描述（可选）|
| startTime | datetime | 开始时间 |
| endTime | datetime | 结束时间（可选）|
| isAllDay | bool | 是否全天 |
| priority | enum | 优先级 |
| reminder | string | 提醒设置 |

### 3.5 异常/边界情况

| 场景 | 处理 |
|------|------|
| 标题为空 | 提交按钮禁用 |
| 结束时间早于开始时间 | Toast "结束时间不能早于开始时间" |
| 网络错误 | 显示错误提示，可重试 |

### 3.6 跳转关系

| 来源 | 触发 | 目标 |
|------|------|------|
| /task/home | 点击"+ 新建任务" | /task/add |
| /task/add | 保存成功 | /task/:id 或 /task/home |
| /task/add | 点击顶部返回 | /task/home |

- 任务状态变为 completed

- 点击"编辑"
- 跳转 `/task/edit/:id`
- 修改后保存返回

#### 删除任务

- 点击"更多" → 删除
- 确认弹窗 → 删除成功返回列表

## 五、模块数据流

```
任务首页 → 新建任务 → 保存 → 任务详情
    ↓
查看任务 → 编辑/完成/删除 → 返回列表

API 调用序列：
1. GET  /task/list              → 获取任务列表
2. GET  /task/:id               → 获取任务详情
3. POST /task/add               → 创建任务
4. PUT  /task/:id               → 更新任务
5. POST /task/:id/complete      → 标记完成
6. DELETE /task/:id             → 删除任务
```

## 六、接口清单

> **注意**：金额字段单位为分（cent），非元。数量字段为整数。

| 页面 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 任务首页 | `/task/list` | GET | 任务列表（支持日期范围筛选）|
| 新建任务 | `/task/add` | POST | 创建任务 |
| 任务详情 | `/task/:id` | GET | 任务详情 |
| 任务详情 | `/task/:id` | PUT | 更新任务 |
| 任务详情 | `/task/:id/complete` | POST | 标记完成 |
| 任务详情 | `/task/:id` | DELETE | 删除任务 |
