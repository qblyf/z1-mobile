### 4.3 核心交互逻辑

#### 基本信息

- 任务标题：必填，限制 50 字符
- 任务内容：选填，限制 500 字符

#### 时间设置

- 开始时间：必填，点击选择日期时间
- 结束时间：选填，需晚于开始时间
- 时间选择器：日期 + 小时分钟

#### 优先级

- 三个选项：低 / 中 / 高
- 默认：中
- 单选

#### 提醒设置

- 下拉选择：无 / 5分钟前 / 15分钟前 / 30分钟前 / 1小时前
- 默认：无
- 设置后，系统在指定时间发送通知

#### 关联会员

- 点击搜索会员
- 调用 `/members/list-phones` 搜索
- 选择后显示会员姓名和手机号

#### 保存任务

- 点击"保存任务"按钮
- 调用 `POST /task/add` 接口
- 成功 → 跳转任务详情或返回列表
- 失败 → 显示错误提示

## 六、字段说明

> 字段类型见 `task-types.dart`。

### 6.1 TaskStatus 枚举（实事）

> 源码：`task-types.dart:34-48`。字段名 `status`。

| key | 中文 |
|-----|------|
| valid | 启用 |
| invalid | 停用 |

> ⚠️ **重要**：`TaskStatus` 只表示任务模板的启用/停用，**不是工作流状态**（待办/已完成）。任务"是否完成"通过单独的接口 `/task/:id/complete` 触发。

### 6.2 其他枚举

| 枚举 | 用途 | 源码 |
|------|------|------|
| `RepeatCycle` | 重复周期 | `task-types.dart:12` |
| `AllowCheckType` | 验收方式（部门负责人/上级/指定/无验收） | `task-types.dart:54` |
| `ResponsibleType` | 责任人类型 | `task-types.dart:76` |
| `TaskTemplateCate` | 任务模板分类 | `task-types.dart:96` |

### 6.3 任务实例状态流转

```
[任务实例创建]
    │
    │  (按 RepeatCycle 自动生成实例)
    │
    ↓
[待办]  ──执行人点击"完成"──→  [已完成]
    │
    │  (过期未完成)
    │
    ↓
[已过期] ──→ 列表中显示红色标签

[已完成] ──(AllowCheckType ≠ noCheck)──→ [待验收]
                                            │
                                            ↓
                                        [已验收] / [验收驳回]
```

> ⚠️ 上述实例状态流转在 task-types.dart 中**无对应枚举字段**，是基于产品语义推断。任务实例的完成状态由前端通过比对 `completedAt` 等字段判断（具体字段需后端确认）。

## 七、异常/边界情况

| 场景 | 处理 |
|------|------|
| 任务列表为空 | 显示空状态"暂无任务" + "新建任务"引导 |
| 日历无任务 | 日期下方无圆点标记 |
| 网络错误 | 显示错误提示，可重试 |
| 状态加载中 | 显示骨架屏 |
| 任务已过期 | 状态标签显示红色"已过期" |
| 未选择开始时间 | 保存按钮禁用 |
