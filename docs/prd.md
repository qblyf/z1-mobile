## 一、产品概述

### 1.1 产品背景

Z1 全网连锁系统是一套面向连锁门店的管理系统，原有 PWA 版本在网络不稳定场景下体验较差，扫码能力受限。现将其重构为原生 Flutter App，以提升离线可用性、扫码性能和用户体验。

### 1.2 目标用户

| 角色 | 场景 |
|------|------|
| 门店店员 | 日常零售开单、库存操作、会员服务 |
| 店长 | 审批处理、订单管理、盘库管理 |
| 总部运营 | 数据查看、任务下发、行事历管理 |

### 1.3 核心价值

- **离线可用**：门店网络不稳定时仍可正常操作，已下载数据可离线访问
- **扫码原生**：商品条码、序列号、二维码一扫即得，告别 PWA 扫码卡顿
- **性能流畅**：原生 App 比 PWA 响应更快，操作更跟手
- **消息推送**：原生推送能力，审批提醒、任务通知即时触达

### 1.4 项目规模

| 指标 | 数量 |
|------|------|
| 功能模块 | 6 大类 |
| 后端 API 模型 | 300+ |
| 后端 API 路由 | 11000+ |
| 目标用户 | 连锁门店店员/店长 |

## 三、功能详细说明

### 3.1 认证模块（P0）

#### 3.1.1 登录

**功能描述**：门店员工通过手机号+密码登录系统。

| 字段 | 类型 | 说明 |
|------|------|------|
| 手机号 | String | 必填，支持任意数字 |
| 密码 | String | 必填 |
| 记住我 | Checkbox | 勾选后保存登录状态 |

**交互流程**：

```
输入手机号/密码 → 点击登录 → Loading → 成功跳转首页 / 失败提示错误
```

**业务规则**：
- 登录成功后保存 Token 到本地
- 记住密码时下次自动填充
- Token 有效期 7 天，过期自动刷新

#### 3.1.2 Token 管理

- 登录成功后返回 access_token 和 refresh_token
- access_token 过期前自动用 refresh_token 刷新
- 刷新失败则跳转登录页
- 退出登录时清除本地 Token

#### 3.1.3 退出登录

- 点击右上角电源图标
- 弹出确认对话框
- 确认后清除 Token，跳转登录页

### 3.3 零售开单模块（P0）

#### 3.3.1 开单入口

**页面**：`/order/retail/entry`

**功能**：
- 显示收款员信息
- 选择销售类型（零售/批发）
- 点击进入开单编辑页

#### 3.3.2 零售单编辑

**页面**：`/order/retail/edit`

**功能流程**：

```
选择客户（可选） → 添加商品（扫码/搜索） → 编辑数量/价格 → 收款 → 完成
```

**添加商品**：
- 方式一：点击扫描按钮，扫描商品条码，系统自动查找商品
- 方式二：点击搜索按钮，输入商品名称或编码搜索

**商品行编辑**：
- 可修改单价、折扣、数量
- 支持删除商品行

**收款**：
- 显示应收金额
- 选择支付方式（现金/微信/支付宝/其他）
- 确认收款后生成订单

**业务规则**：
- 商品数量默认 1
- 单价不能为负
- 必须至少添加一个商品才能收款
- 收款后生成订单号，跳转订单详情

#### 3.3.3 API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/order/shop-sale/add` | POST | 创建零售单 |
| `/order/shop-sale-list` | GET | 零售单列表 |
| `/order/:orderNumber` | GET | 订单详情 |
| `/order/:orderNumber/print` | GET | 打印小票 |

| `/stock-taking/list` | GET | 盘库单列表 |

## 六、非功能性需求

### 6.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | ≤ 2 秒（网络正常） |
| 扫码响应时间 | ≤ 1 秒 |
| 列表滑动帧率 | ≥ 60 FPS |
| APK 启动时间 | ≤ 3 秒 |

### 6.2 离线能力

- 已登录用户可查看缓存的订单列表
- 离线时扫码仍可工作（本地商品库）
- 离线操作记录待网络恢复后同步

### 6.3 安全要求

- Token 存储使用安全存储（flutter_secure_storage）
- 不在日志中打印敏感信息
- API 请求全部使用 HTTPS

### 6.4 兼容性

| 项目 | 要求 |
|------|------|
| Android | 5.0+（API 21） |
| iOS | 12.0+ |
| Flutter | 3.x |
| 屏幕适配 | 主流手机分辨率 |

### 6.5 数据规范

- 所有时间使用 UTC，页面展示转为本地时间
- 金额精确到分（元），显示时保留两位小数
- 手机号脱敏显示（中间四位为 *）

## 七、技术架构（参考）

详见 `project-design.md`（项目设计文档）。

### 7.1 技术栈

| 层级 | 技术选型 |
